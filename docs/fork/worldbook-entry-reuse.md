# 世界书逐条复用

## 边界与接口

世界书仍按既有规则激活、排序并执行 EJS；蓝灯 EJS 仍在动态区，比较的是执行后的实际输出，不是模板源码。`renderedEntries: { ref, text, location }[]` 从 Foreground Worldbook 经 Context Planner 的 `world-book.entries`、ForegroundFrame 的 contribution.entries 传至 Session Adapter，不再先拼整包后丢失身份，也不二次执行已经投影的宏。

`worldbookSnapshot(session, entries, pendingMessages)` 返回 `null` 或 `{ schemaVersion: 2, entries: [{ ref, text }], text, rendered }`。返回的 entries 只记录本次真正追加的条目。canonical ref 沿用上游世界书 resolver 的结果；插件自带的非条目章节按来源作为不透明单位，不从正文猜条目。后台整段调用也对接此数组接口，但仍以不透明整段更新，不扩展前台逐条复用的范围。没有网络接口或新的依赖。外壳统一使用 `promptSection('worldbook_context', text)`；不透明章节仅通过 `promptSectionBody` 解开已识别的世界书外壳，正文空白与自定义标签保持原样。

每次从当前 Session Surface 和待追加消息重建有效版本索引；只有消息正文仍包含记录的 rendered 文本才计为可见，同 ref 以后出现的版本覆盖以前版本。直接比较 text，不新增哈希。压缩、回退和放弃替代生成自然改变这个 Projection；Chat 的已读/冷却记录不是复用依据，激活规则与冷却期限不变。普通绿灯的旧内容不被删除，新增或变化只追加到末尾，前台历史及稳定前缀字节不改。

## 跨条目结构

在有身份的渲染条目内匹配跨条目的成对 XML 标签（包括 EJS 生成的标签），保留原顺序及标签属性。只追加变化条目；被跳过条目中用于包围这些变化的开闭标签作为结构支架保留，不重发其中的正文。嵌套组仍完整包围增量，不把整组未变内容再次发送。独立条目无需支架；没有增量则不发送空组。

## 压缩与升级

「最近原文」附录只接纳真实玩家文本及 assistant 正文；插件世界书、前台帧、工具结果和其他派生设定不进入附录，也不占原文保留预算。给摘要模型的既有前缀不改写。

旧 v1 整包记录没有条目身份，不推测切段，也不改写存档或历史；升级后首次被选中的条目重新建立 v2 记录。已经累计的旧副本不会因部署立刻消失，正常压缩后释放。旧附录已经失去来源信息的文字不做猜测式清洗。离线回放在真实请求副本上使用同轮召回日志的结构化 outputs，衡量从可见请求边界开始采用此策略的收益，不宣称在线历史已经被重写。

## 验证

新增一个行为测试，覆盖新增/不变/变化、真实蓝灯 EJS、当前有效版本、回退、压缩、待追加消息、历史字节稳定和跨条目嵌套标签；扩展现有压缩测试覆盖附录与保留预算排除派生设定。离线回放结果另记任务报告，禁止付费调用或写入真实数据。接入英文 XML 外壳后，世界书字符数从 164035 降至 93007，节省 71028；其中相同正文从 7 份降至 1 份，节省 71226 字符。相较旧外壳，7 次追加合计增加 210 字符；非世界书消息完全不变。

后续单独评估「动作」「移动速度」「银武」等泛关键词的过度召回；本次不调整关键词、预算或模型上下文阈值。
