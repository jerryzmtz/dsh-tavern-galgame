# 作者指南：把人物卡做成 galgame 舞台

写给 SillyTavern 老用户和卡作者，假设你已经按 [README](../README.md) 装好、配好模型，并能在大肥鱼示例里看到舞台。这里只介绍能做什么；具体怎么点、怎么改，问应用里的 AI（见文末）。

## 先复制一份

「保存字段」会直接改原卡。改卡前在人物卡库里「另存副本」。副本带着封面、世界书和舞台设置，但和原卡共用同一批素材包。

## 设置向导

普通卡在「舞台设置」里点「启用舞台（对话气泡）」后，「设置向导」分三步：挑选素材 → 自定义角色 → 开场画面。挑中的素材会复制进这张卡专用的「本卡素材包」，改它不影响别的卡。第一次在没有素材的卡上进入舞台时，向导会自动打开一次。

## 素材包与影响范围

人物、背景、CG、音乐、音效、环境音都放在素材包里，卡通过「全局 / 本卡 / 关闭」使用素材包。包里的条目像世界书一样亮灯：蓝灯每轮可用，绿灯在正文出现名字或触发词时可用。改包里的内容会影响所有用到这个包的卡；只想改一张卡时，先复制这个包。

## 人物、服装与差分

每个人物可以有多套服装，所有服装共用同一组差分（情绪），导演按台词选择服装和差分。立绘可以上传，也可以用应用内生图生成（按次付费）；Live2D 和 Spine 模型可以导入。Live2D 和 Spine 运行库不随应用分发，需要在「设置 › DSH Tavern › 运行库」里自行导入；没有运行库时舞台改用静态立绘。

## 模组

物品演出、手机、文字演出是模组。模组开关在「基础设置」里，对所有卡生效；不同卡的差别来自素材，例如只给某张卡绑定的物品包。演出何时出现由导演按剧情决定。

## 导出分享

「舞台设置 › 素材包 › 导出」把人物卡、封面和勾选的素材包打成一个 ZIP。对方用「导入人物卡」选这个 ZIP，就会新建一张卡并装好素材。

## 详细做法：问应用里的 AI

在「卡片」模式里直接问。它已经内置了上面每项功能的说明，能告诉你在哪里点，也能直接帮你改。例如：

- 「这张卡怎么开舞台？设置向导每一步要做什么？」
- 「我只想改副本卡的人物立绘，不想影响原卡，怎么做？」
- 「给女主加一套泳装，再加一个"害羞"差分。」
- 「怎么导入 Live2D 模型？提示缺少运行库怎么办？」
- 「手机短信什么时候会弹出来？物品怎么只在这张卡出现？」
