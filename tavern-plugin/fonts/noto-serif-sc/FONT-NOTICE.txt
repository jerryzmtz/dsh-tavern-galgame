The repository's bin/fork-install-fonts.py previously instantiated the source
variable font at wght=400/500/700 with fontTools and encoded WOFF2, preserving
all Unicode mappings (no subsetting). This release copies those installed
instances byte-for-byte; no glyph outlines, metrics, or vertical ink table are
changed here. The OS/2 weight of each file matches its declared CSS weight;
the original ExtraLight name records remain from variable-font instantiation.
