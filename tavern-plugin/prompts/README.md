# 提示词目录

这里存放 dsh-tavern 自身使用的固定提示词。通常修改后无需重启，下一次相关模型调用会直接读取新内容；已经开始生成的回复不受影响。文生图的三份提示词也可在“系统提示词”面板编辑、导入导出及恢复默认；用户覆盖保存在设置中，不直接修改内置文件。

场景生图 Agent 分为两层：

- `scene-image-system.md`：轨迹中的“初始系统提示词”，规定 Agent 身份及长期行为边界。在系统提示词组装时读取当前设置，已有 Agent 也会在后续请求中使用修改后的内容，无需重启。不改写旧轨迹。
- `scene-plan.md`：画面规划任务提示词，追加在每次任务消息的“任务要求”中，每次规划时读取。
- `scene-image-adjustment.md`：带意见重画、表达转换的任务提示词，与画面规划指令二选一，每次相关任务时读取。

“最近剧情与本次任务”中的正文、变量片段、已有方案和重画意见是动态材料，仍由代码组装；模型展示的思考过程不是固定提示词。这些文件不包含发送给生图供应商的最终画面描述或请求参数。

场景生图的 `character_design_read` 工具在 Agent 初始化时注册，定义常驻于工具前缀，规划和带意见重画均可使用；只切换本次任务的历史快照，空闲时不可读取。没有对应时期的已结算档案时返回缺失，不借用最新档案；不开放 `character_design_save`。

画面方案只要求每个变化字段输出 `text` 和 `tags`，不再要求身份引用、出处或证据。人物内部编号由程序按游戏、目标正文和局部人物编号生成。旧方案保留原样，旧会话偶尔输出的引用字段会被忽略，不作为已验证证据保存。原文匹配与逐字段来源校验已取消，字段结构、连续性、版本隔离及参考图授权校验仍保留。

人物卡、Guide、姿势、世界书正文、剧本分块和聊天记录等动态上下文不写在这些文件中，由代码在运行时按需注入。

Agent 的固定规则、新会话欢迎语和卡片对话起始入口追加的任务模板属于这里。普通按钮文字、工具参数说明以及人物卡内用户自定义的 `system_prompt` 不属于这里。


- `card-system.md`：卡片 Agent 的自定义 system 指令，包含改卡记忆的记录与验证边界。直接编辑此文件，下一次请求读取最新内容；空白时不注入自定义 system 段，工作区说明仍保留。各入口的 `card-task-*.md` 任务指令独立保留。

- `card-workspace.md`：卡片 Agent 工作区说明默认模板，可在前台“系统提示词 → 卡片 Agent 工作区说明”修改、保存或恢复默认。`{{resourceRoot}}` 和 `{{projectionPaths}}` 在发送前替换为当前会话路径。

- `card-reference.md`：绑定了人物卡的卡片会话（含“修改人物卡”入口）在 system 中附带人物卡基本信息、人物卡系统提示与常驻世界书快照，此文件是放在这些资料之前的说明，提醒卡片 Agent 它们只是开局参考、以工具读取的当前文件为准。
