# 编写场景写作 Skill

把用户引用的现成写作教导整理成前台按场景使用的独立 Skill。

1. 阅读用户明确引用的素材。尚未引用材料时，请用户在“剧本与素材库”引用所需材料；导入动作本身只负责存储。
2. 从材料中提取明确的写作方法，以及适用场景、不适用场景。材料缺少边界、互相矛盾或用户偏好会影响取舍时，向用户询问具体场景后再定稿。已有明确答案的部分无需重复询问。方法应来自材料，不自行发明教学内容。
3. 简介包含可识别的场景触发条件与必要排除条件。完整正文写清适用场景、不适用场景、写作方法和必要例子，使前台加载正文后即可执行。渐进式披露只分两层：先根据简介判断场景，再加载完整正文。
4. 写作 Skill 本身就是独立的场景提示词，不拆分参考文件，也不要求前台读取素材。素材只在创建时提供依据；所需方法整理进正文，删除原素材后仍完整可用。
5. 调用 `tavern_save_skill`，设置 `purpose: writing`，默认允许模型自动调用，默认分配前台 Agent。仅在用户要求时改变分配。提交完整 `body`，并设置 `references: []`。修改已有写作 Skill 时，先读取其原有参考文件，将仍需要的方法合并进正文、移除参考链接，再用空数组清理旧参考文件。

前台根据当前场景自主选择与加载，正文中无需解释用了什么 Skill。Skill 只指导表达，人物卡事实、玩家选择及 Agent 工具权限仍按现有规则执行。

保存后简短告知名称、适用边界和分配用途。用户可以在 Skill 库中查看、调整用途或删除它，并在本局设置中开关写作 Skill。
