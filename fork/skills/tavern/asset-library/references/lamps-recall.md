# 灯态与触发词

## 每轮导演能看到什么

一个条目要进入本轮导演的候选目录，需要同时满足：所在包对当前卡生效（全局启用或绑定到本卡）、条目启用、对应的全局舞台开关开着（音乐、音效、环境音等）、媒体可用。在此之上：

| 条目灯 | 本轮是否提供给导演 |
| --- | --- |
| 蓝灯 `constant` | 每轮都提供 |
| 绿灯 `keyword`，触发词命中 | 提供 |
| 绿灯，未命中 | 只有配置了智能判断时，由判断按相关概率补入（每类有上限）；没配置就不提供 |
| 关 `enabled:false` | 永不提供 |

没被提供不等于停止：已经在舞台上的音乐、环境音、背景会保持，直到导演明确换掉或停止。智能判断的配置属于 stage-directing。

## 怎么选灯

- 蓝灯适合几乎每轮都可能用到的东西（主场景背景、本卡主题曲）。蓝灯越多，每轮发给导演的内容越长。
- 绿灯适合只在特定情节出现的东西（"雨夜""医院""战斗曲"）。
- 用户想暂时不用某条素材，关灯即可，不必删除。
- 演出风格（`directions`）只有蓝灯和关，没有绿灯；它的编写属于 stage-directing。

## 触发词

- 条目名称本身就是触发词，不要把完整名称再写进 `recall.keywords`。
- 关键词写简短、有辨识度的叫法：名称中的关键子词、昵称、常见替代写法。例如名称"深夜便利店"可以写 `["便利店", "罗森"]`；不要写"夜晚""商店"这类会频繁误中的泛词。
- 拉丁字母不区分大小写，不需要重复大小写变体。音译或别称放在 `synonyms` 里，按关键词分组，例如 `{"Claude": ["克劳德"]}`。
- 背景的关键词不要用纯时间词（"早上""夜里"）；时段由背景的 `variants`（morning/day/dusk/night）和导演的时间指令处理。
- 当前限制：每条最多 16 个关键词，每词 2–40 字（服装 1–40 字），每个关键词最多 6 个别称；`directorNote` 最多 300 字。以 `schema` 返回的 limits 为准。
- 人物没有关键词，名字和别名就是它的触发词，见 figure-assets。

## 例子

用户："学校天台的背景只在去天台时出现就行，别每轮都给导演。"
→ `item` 读取该背景，确认当前是蓝灯；改为 `recall.mode:"keyword"`，关键词 `["天台", "屋顶"]`；回读确认。告诉用户：之后正文提到天台或屋顶时导演才会看到它，当前已经显示的背景不会因此被换掉。
