# Dafeiyu Picker Cover

`cover.png` is the approved, owner-authored cover derived from the original
`images/fullbody/dafeiyu-baseline-v2.png` illustration: crop 900 x 1200 at
(200, 0), background #EAF1FA, output 600 x 800. It is the same image used by
the installed example card, with all original card text metadata removed.
Artwork: CC BY-NC-SA-4.0; retain kousakayou attribution and the example pack's applicable source notices.
It is not an asset-pack cover field.

Card-bundle schema v1 now includes an optional `cover` entry. The example ZIP
contains `card/cover.png`; importing the ZIP through Import character card
installs the card, its bound packs, and its picker cover together. Download
`dafeiyu.card-bundle.zip`, import it and confirm the packs, then start a new game.
No separate PNG import is required. Older bundles without a cover still import.

The exporter also emits `dafeiyu.card.png` as an optional standard PNG card,
embedding only the freshly generated public card JSON in a `chara` chunk.
The stage figure remains independent of the picker cover.
